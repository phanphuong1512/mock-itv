# MockITV

MockITV is an AI-powered mock interview platform that simulates real technical interviews. It generates position-specific questions via Function Calling, evaluates candidate answers with verbatim highlighting (word-by-word color analysis), and supports real-time voice interviews with streaming STT + Vietnamese TTS.

## Features

- **AI Mock Interviews:** 7 pre-configured job positions across Backend, Frontend, DevOps, AI/ML, and Fullstack
- **Verbatim Highlighting:** Color-coded analysis (green/yellow/red) for each chunk of your answer with popup tooltips
- **Voice Interview:** Real-time streaming STT (Sherpa-ONNX, offline) + Vietnamese TTS (Edge-TTS)
- **CV Personalization:** Upload CV → AI analyzes skills & gaps → generates personalized questions
- **Custom Mock via RAG:** Upload CV/JD → Pinecone VectorDB → context-aware question generation
- **Batch Evaluation:** Single API call evaluates entire session (80% token savings)
- **Dark/Light Mode + Bilingual (VI/EN)**

## Folder Structure

- `/backend`: FastAPI server, SQLite database, LangChain AI core, and voice processing (Sherpa-ONNX/Edge-TTS).
- `/frontend`: Next.js 16 application containing the UI, React components, and client-side logic.
- `/docs`: Detailed project documentation, architectures, and MVP specs.
- `/logs`: Contains server log files (`backend.log` and `frontend.log`) generated by the startup scripts.
- `/resources`: Contains sample resources (e.g., sample CV/JD PDFs) for testing.

## Zero-Config Quick Start

This project uses an in-memory SQLite database that auto-seeds itself on the first run, making it extremely easy to set up and test.

### macOS & Linux
Just run the one-click startup script from the root directory:
```bash
./start.sh
```

### Windows
Double-click `start.bat` or run it from the command line:
```cmd
start.bat
```

The script will automatically:
1. Check and clear any active processes on ports `3000` (frontend) and `8000` (backend) to prevent port conflicts.
2. Create a Python virtual environment and install backend dependencies.
3. Install frontend Node.js dependencies.
4. Download the necessary offline AI models (for STT) if they don't exist.
5. Start the FastAPI backend server on `http://localhost:8000` using `uvicorn` with auto-reload.
6. Start the Next.js frontend server on `http://localhost:3000`.
7. Output all server logs cleanly to the `logs/` folder (`logs/backend.log` and `logs/frontend.log`).
8. Open your default web browser to the application.
9. Terminate both backend and frontend servers cleanly when you press `Ctrl+C` (on macOS/Linux) or `ENTER` / close the terminal window (on Windows).

## Manual Setup

If you prefer to start the servers manually:

### 1. Backend Setup (Python 3.10+)
```bash
cd backend
python -m venv venv

# Activate virtual environment
# On macOS/Linux:
source venv/bin/activate
# On Windows:
# venv\Scripts\activate

pip install -r requirements.txt

# Configure environment
cp .env.example .env
# Edit .env and fill in your API keys

# Download AI models for Voice features
python download_model.py

python -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```
*The backend will automatically create `mockitv.db` and seed it with test data.*

### 2. Frontend Setup (Node.js 18+)
```bash
cd frontend
npm install
npm run dev
```

## Environment Variables

```env
# backend/.env
DATABASE_URL=sqlite:///./mockitv.db

# LLM API (OpenAI-compatible endpoint)
OPENAI_ENDPOINT=https://aiportalapi.stu-platform.live/jpe
OPENAI_API_KEY=<your-api-key>
OPENAI_MODEL=GPT-5.4

# Pinecone VectorDB (required for Custom Mock RAG feature)
PINECONE_API_KEY=<your-pinecone-api-key>
PINECONE_INDEX_NAME=mockitv
EMBEDDING_API_KEY=<your-embedding-api-key>
```

## Tech Stack

- **Frontend:** Next.js 16, React 19, TypeScript, Tailwind CSS v4, Framer Motion
- **Backend:** FastAPI, SQLAlchemy, SQLite (WAL mode), Uvicorn
- **AI Engine:** LangChain + OpenAI SDK (Function Calling, Batch Evaluation)
- **RAG:** Pinecone VectorDB + text-embedding-3-large (1024 dimensions)
- **Voice:** Sherpa-ONNX (streaming STT, offline) + Edge-TTS (Vietnamese Neural Voice)
- **CV Parsing:** pypdf + python-docx
